# 💜 Smart Productivity System

### A Smart Productivity Website for Personal and Professional Task Management

## 📌 About the Project

The Smart Productivity System is a web-based application designed to help students and professionals manage their daily activities efficiently.

It provides an integrated platform to organize tasks, set goals, track habits, plan schedules, manage time and monitor productivity.

The main aim of this project is to improve time management, reduce procrastination and increase daily productivity.

## 🎯 Project Objectives

- To manage daily and important tasks.
- To improve time management.
- To track daily habits and goals.
- To provide reminders and scheduling.
- To monitor individual productivity.
- To encourage consistent work habits.

## ✨ Key Features

### 1. Dashboard
- Displays productivity summary.
- Shows total and completed tasks.
- Displays active goals and tracked habits.

### 2. Task Management
- Add new tasks.
- Set task priorities.
- Select due dates.
- Mark tasks as completed.
- Delete unwanted tasks.

### 3. Calendar
- View monthly calendar.
- Identify the current date.
- Organize daily schedules.

### 4. Goal Management
- Create personal goals.
- Set target dates.
- Track active goals.

### 5. Habit Tracker
- Add daily habits.
- Mark habits as completed.
- Monitor daily habit progress.

### 6. Daily Planner
- Prepare daily schedules.
- Save daily plans.
- Organize activities.

### 7. Focus Mode
- Set focus session duration.
- Start, pause and reset the timer.
- Improve concentration.

### 8. Journal
- Record daily thoughts.
- Save personal notes.
- Maintain daily reflections.

### 9. Productivity Analytics
- Display total tasks.
- Calculate completed tasks.
- Show task completion percentage.

### 10. Settings
- Manage user profile.
- Update name and email.

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/Smart-Productivity-System.git
```

2. Open the project folder in Visual Studio Code.

3. Open the `index.html` file.

4. Install the Live Server extension.

5. Right-click the HTML file.

6. Select **Open with Live Server**.

7. The Smart Productivity System website will open in your browser.
